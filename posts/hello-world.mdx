## 안녕하세요!

이 블로그는 **Next.js**와 **GitHub Pages**로 만들어졌습니다.

## 기술 스택

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Content**: MDX
- **Hosting**: GitHub Pages

## 앞으로의 계획

앞으로 개발하면서 배운 내용들을 이곳에 기록할 예정입니다.

```typescript
// 예시 코드
function greet(name: string): string {
  return `Hello, ${name}!`;
}
```

> 좋은 코드는 그 자체로 문서가 된다.
